# Docs/Shots - the only pictures in the repository

23.07 (ROADMAP section 29). A screenshot is the proof of THE LOOK to the owner,
and never a test: the digests beside it are the proof to the tests. Each
picture here is dated, named after what it shows, and stands beside the sky
line of the world it shows - `Vaelen.Shot <name>` writes
`Saved/Screenshots/<name>.png` and prints `LogVaelenWalk: shot <file> of
LogVaelenScene: AELVOR ... sky day D: ... sun azimuth A elevation E ...; sky
<hex>` in the same breath, so the two land together in the sitting's log.

took it (`git add Docs/Shots/<name>.png`, PNG, 1920x1080 at most).
